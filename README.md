### 📌 Featured Projects

#### 🤖 [Agent Parallel System](https://github.com/banchen21/agent-parallel-system)

Multi-agent collaboration platform built with Rust + Actix Actor model.

- REST + WebSocket + SSE triple-interface backend
- DAG-based task orchestration with Neo4j graph memory
- React + TypeScript frontend: [aps-web-ui](https://github.com/banchen21/aps-web-ui)
- PostgreSQL + Redis + JWT multi-workspace isolation

#### 🎮 [MC AI Buddy](https://github.com/banchen21/mc-ai-buddy)

LLM-powered Minecraft bot using Mineflayer + DeepSeek.

- Raycast-based vision, persistent memory, auto-reconnect
- Natural chat interaction with players in-game

Dual-UI shop & pawnshop system for Minecraft Bedrock.

- GUI form interface + chat-based command system
- Full shop lifecycle: create, edit, transfer, audit logs
